# hints/

Optional helpers for the course labs. Nothing in here is required — every lab
tells you when (and whether) to open a file from this folder.

- `repro/` — one script per planted bug that makes it happen on demand.
  Run them against a locally running API (`uv run campuscrave`).
- `CLAUDE.md.final` — the project memory file you will write *with* the course
  in Episode 13. Don't copy it in early; writing it yourself is the lesson.

Spoiler policy: scripts reproduce bugs, they don't explain or fix them.
The `solutions/*` branches appear as each bug is solved on screen.
